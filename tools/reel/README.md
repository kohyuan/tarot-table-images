# リールの動画を作る道具

表 reels_post の1行分の中身を渡すと、リールの動画（33.3秒）を1本作ります。

流れ：カードが右から流れて3枚が伏せて置かれる → 見出しと問い、「直感で、左・中・右から一枚選んでください」（考える時間 3.5秒）→ 左・中・右を1枚ずつめくる（各7秒）→ 3枚を並べて見せる → アプリのホーム画面で締める。

## 準備（初めの1回だけ）

```
cd tools/reel
npm install
```

ほかに ffmpeg と、Chromium（headless）が要ります。Chromium は次の順で探します：環境変数 `PLAYWRIGHT_CHROME` → `/opt/pw-browsers` → `~/.cache/ms-playwright`。

## 使い方（リポジトリの根から）

```
node tools/reel/make_reel.mjs --params reel.json --out reels/R0001.mp4
```

reel.json の形：

```json
{
  "post_id": "R0001",
  "headline": "明日からの7日間 10/23(金)~10/29(木)のお金・買い物",
  "question": "お金の出入りや買い物は、この7日間でどう動きやすいでしょう。",
  "cards": [
    { "id": "S02", "pos": "U", "keyword": "迷い", "reading": "読みの文" },
    { "id": "M17", "pos": "U" },
    { "id": "S09", "pos": "R" }
  ]
}
```

| 項目 | 表の列 | 中身 |
|---|---|---|
| `post_id` | B | 表示には使わない（書き出しの記録用） |
| `headline` | I | 「〜の」より後ろを大きく、前を小さく出す。後ろの部分を変えたい時は `"theme"` を足す |
| `question` | J | 考える時間に出す問い |
| `cards[].id` | G | 左・中・右の card_id（M00〜M21、W/C/S/P + 01〜14） |
| `cards[].pos` | H | `U`（正位置）か `R`（逆位置）。逆位置はカードごと上下を逆にして出す |
| `cards[].keyword` | — | 無くてもよい。あればカード名の横と、最後の3枚の下に出す。無ければカード名を出す |
| `cards[].reading` | — | 無くてもよい。あればカードの下に読みの文を出す。無ければ何も出さない |

文が長すぎる時は文字を小さくして収めます。一番小さくしても収まらない時は、動画を作ったあとエラーで止まります。

## カードの絵

`cards/<card_id>.jpg`（`.png`・`.webp` も可）を使います。絵の無いカードは、紺地に金の星とカード名の仮の表面で出します。最初に流れるカードの列には、置いてある絵を全部使い、足りない分は仮の表面で埋めます。

## 音

`audio/` に、左・中・右の正逆の組み合わせ8通り（`UUU.m4a`〜`RRR.m4a`）を置いてあります。逆位置のカードをめくる所だけ、少し低い響きになります。音量は -14 LUFS にそろえてあります。作り直す時だけ `audio/src/bake.sh` を使います（Lemo-Opuscar の音の部品が要ります。普段は要りません）。

## 出来上がりの確かめ

書き出したあと、次を自分で確かめ、外れていればエラーで止まります：MP4、映像 H.264、音声 AAC、1080x1920、長さ3〜90秒、問いと読みの文が枠に収まっていること。

2コアの機械で、1本およそ70秒かかります。

## ファイル

- `make_reel.mjs`：書き出しの本体
- `page/index.html`・`page/film.js`：動画の画面（時刻を渡すとその瞬間を描く）
- `page/card_back.png`：カードの裏
- `audio/`：音
